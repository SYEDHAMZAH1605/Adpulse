# AdPulse

AdPulse is a responsive SaaS dashboard prototype for digital advertisers and marketing agencies. It brings campaign performance, channel analytics, budget planning, and explainable optimization signals into one local, interactive workspace.

## Problem statement

Paid media results are spread across platforms, making it difficult to compare channel efficiency, identify campaigns that need attention, and decide where to move budget. AdPulse demonstrates a consolidated view that turns campaign metrics into practical next steps.

## Target users

- Performance marketers managing campaigns across multiple ad platforms
- Marketing agencies comparing client or channel results
- Growth leads planning and reviewing paid media budgets

## Main features

- **Overview:** account-level spend, impressions, clicks, conversions, CTR, CPC, and ROAS calculated from campaign records
- **Campaigns:** eight editable sample records across Google Ads, Meta Ads, and Display; search, platform and status filters; sortable columns; campaign detail modal; CSV export
- **Analytics:** campaign spend versus revenue, channel spend share, and monthly conversion trends, reflecting the current campaign filters
- **Budget planner:** interactive monthly budget sliders, allocation envelope, remaining/over-budget amount, current-versus-proposed comparison, and clearly identified illustrative revenue estimates
- **Insights:** transparent rules for low ROAS, higher CPC, spend without enough conversions, and strong returns
- **Responsive interface:** sidebar navigation, mobile navigation, responsive charts and tables, loading-free local data, and useful empty states

## User stories

- As a performance marketer, I want to compare spend, revenue, and ROAS across campaigns so that I can spot efficient and inefficient investment.
- As an agency analyst, I want to search and filter campaigns by platform and status so that I can focus on a subset of results.
- As a growth lead, I want to test budget allocations and see the assumptions behind the estimates so that I can discuss trade-offs responsibly.
- As a campaign owner, I want a concise, understandable signal when a campaign may need attention so that I can prioritize a review.
- As a marketer, I want to export the visible campaign results so that I can continue analysis outside the prototype.

## MVP prioritization

1. **P0 — Core decision support:** consistent campaign data and account metrics, campaign table and details, filters, sorting, analytics charts, budget adjustments, and explainable recommendations.
2. **P1 — Workflow quality:** CSV export, responsive navigation and layouts, resettable budget plan, empty states, and product documentation.
3. **P2 — Future product work:** connected ad accounts, saved plans, collaboration, permissions, alerts, and configurable attribution.

## Technology stack

- React 19 and JavaScript
- Vite
- Recharts
- Lucide React
- CSS (global reset and application stylesheet)
- Local JSON campaign data; React state for filters and budget changes

No backend, paid API, or API key is required.

## Setup

Requirements: Node.js compatible with the installed Vite version and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. To create and preview a production build:

```bash
npm run build
npm run preview
```

## Current limitations

- All campaign values are static, illustrative sample data and are not connected to advertising accounts.
- The reporting period is fixed to the sample data (June–November 2026); configurable date filters are not included.
- Budget projections linearly scale each campaign’s historical revenue using its original monthly budget as the baseline. This is a planning estimate, not a forecast or guaranteed result.
- Insight rules use fixed thresholds in the frontend and are not generated by a trained AI model.
- Budget edits are held in browser memory and reset on page reload; there is no persistence or multi-user synchronization.
- The prototype has no authentication, role management, or backend.

## Future improvements

- Integrate authorized Google Ads, Meta Ads, and display-network reporting APIs with clear attribution and refresh status.
- Add configurable date ranges, conversion windows, attribution models, and currency/time-zone settings.
- Persist budget scenarios, compare named scenarios, and support team review and approval.
- Let teams tune insight thresholds and provide alert history and explanations.
- Add automated unit and browser tests for calculations, filtering, accessibility, and responsive workflows.
